# Sessions

One file per session, written when you say `close`.

Fixed shape: what the session was for · what moved · what was decided · what was abandoned · where it stopped · the one open question for next time.

**These are read on demand, never on resume.** Starting a new session loads `wiki/index.md`, the status line of `story/TREATMENT.md`, and `wiki/abandoned.md` — and nothing else. That is what stops session twelve costing twelve sessions of context.

Ask for one by name if you want it: *"what did we do in session three?"*
