# Transcripts

Put one plain text (`.txt`) or Markdown (`.md`) file here for each contribution: a typed note, or the transcript of a recording.

Name each file so you can find its source later, for example `anna-park-bench.md` or `04-market-recording.txt`.

This file is not a contribution. It is here because git does not keep empty folders, and without it the download would have no `transcripts` folder.
